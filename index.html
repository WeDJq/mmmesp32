Шаг 1: Конвертация .pcap в .hc22000

Загрузи свой файл захвата (`.pcap`, `.cap`, `.pcapng`). Библиотека capJS извлечёт из него данные рукопожатия и выдаст строку для перебора.

Внимание: Файл cap.min.js должен лежать в той же папке, что и этот HTML-файл. Если сайт пишет «библиотека не найдена», проверь это.

Шаг 2: Перебор пароля

        
Скопируй полученный хэш (или используй исходный `.pcap`) и переходи на инструмент aircrack-js. Он работает в браузере и поддерживает GPU.

        
        

            Инструкция:
            
    
                
  1. Нажми кнопку ниже, чтобы открыть aircrack-js.
    2. 
                
  2. Загрузи туда свой `.pcap` файл или вставь скопированную строку `.hc22000` в поле для хэшей.
    3. 
                
  3. Выбери встроенный словарь (SecLists) или загрузи свой `.txt` файл со списком паролей.
    4. 
                
  4. Нажми Start и жди результат.
    5. 
            

            
Совет: для учебного слабого пароля (например, `12345678`) результат появится за секунды.
