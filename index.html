Учебный стенд: конвертация захвата трафика и подготовка к перебору пароля.

Шаг 1: Конвертация .pcap в .hc22000

Библиотека `capJS` больше не доступна для скачивания. Но мы используем её онлайн-версию, которая работает прямо в браузере и не загружает твой файл на сервер.

Что делать:
  1. Нажми на кнопку ниже, чтобы открыть онлайн-конвертер.
  2. Загрузи туда свой `.pcap` файл.
  3. Скопируй полученную строку (она будет начинаться с `WPA*02*...`).
Открыть онлайн-конвертер

Шаг 2: Перебор пароля

Теперь, когда у тебя есть хэш в формате `.hc22000`, переходи к инструменту aircrack-js. Он работает в браузере и поддерживает GPU.

Что делать:
  1. Нажми кнопку ниже, чтобы открыть aircrack-js.
  2. Вставь скопированный хэш в поле для хэшей или загрузи исходный `.pcap` файл (инструмент понимает оба формата).
  3. Выбери встроенный словарь или загрузи свой `.txt` файл со списком паролей.
  4. Нажми Start и жди результат.
Перейти к aircrack-js для перебора
